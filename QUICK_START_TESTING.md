## 🐛 ТИПИЧНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема: Видео не загружаются
**Решение:**
```bash
# Проверьте, что видео файлы есть
ls -la public/videos/

# Проверьте права доступа
chmod 644 public/videos/*.mp4
```

### Проблема: Форма не отправляется
**Решение:**
```bash
# Проверьте, что API работает
curl -I http://localhost:3000/api/contact

# Проверьте консоль браузера на ошибки
# F12 → Console → смотрите ошибки
```

### Проблема: Стили не загружаются
**Решение:**
```bash
# Пересборка Tailwind
npm run build

# Очистка кэша
rm -rf .next
npm run dev
```

### Проблема: localhost не отвечает
**Решение:**
```bash
# Проверьте, что port 3000 не занят
lsof -i :3000

# Если занят, убейте процесс
kill -9 <PID>

# Перезапустите dev-сервер
npm run dev
```
